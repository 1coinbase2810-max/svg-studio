01 — The studio

Everything a mark needs.

Describe it, refine it, export it — without leaving the tab. Every control is built for one job: turning a sentence into a finished mark.

01

Description in, design out

Write “gold crown, shield frame, star sparkles” in English or Persian. The engine detects the shape, palette, ornaments and frame from the words. No account, no API call.

02

Typography, tuned

Eleven typefaces and eleven treatments — split two-tone, 3D offset, hollow neon outline, tech brackets. Set the case, size, tracking or bend it on a curved path.

03

Ornament system

Orbit rings, speed lines, star sparkles, geometric grids and ambient glow. Toggle each one, or let the description pick the ornaments for you.

04

Layout & mockups

Six compositions, six frames, full z-order and opacity control. Preview the mark on a business card, an app icon, a website header or apparel before you commit.

05

Exports that scale

Download SVG, HD PNG, or a seven-size icon ZIP. Strip the background, embed the fonts, copy the raw code. The mark leaves clean and editable.

06

Bilingual, offline

Switch the entire interface between English and Persian, with RTL typography built in. Everything runs in the tab; your files never leave the machine.
